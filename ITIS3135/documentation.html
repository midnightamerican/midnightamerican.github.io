Introduction

CSS controls layout, colors, and fonts.

It separates design from content.

body { background-color: #f0f0f0; }
Selectors and Visuals

Selectors target elements for styling.

[class*="btn"] { border-radius: 4px; }
Box Model

Includes margin, border, padding, and content.

div { padding: 20px; }
Flexbox Layout

Used for responsive layouts.

display: flex;
Media Queries

Used for responsive design.

@media (max-width: 600px) { ... }
