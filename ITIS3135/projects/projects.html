NFL Passing Touchdown Prediction Model

📊 Data Range: 2016 – 2025

In this project, we developed a predictive model to estimate NFL passing touchdowns for the 2026 season. Using historical data including passing yards, interceptions, and passing touchdowns, we analyzed trends and relationships to forecast future performance.

Our approach focused on identifying key statistical indicators that most strongly influence touchdown production, allowing us to build a model that provides meaningful projections for quarterbacks.

🔍 Key Features:

  • Data-driven analysis of quarterback performance
  • Use of multiple variables (yards, INTs, TDs)
  • Predictive modeling for future seasons
