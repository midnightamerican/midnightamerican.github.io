Project Overview

This web application is a landing page for the Charlotte Sports Analytics Club. The purpose of the website is to promote the club, showcase student-led analytics projects, and increase engagement across campus. The site will serve as a central hub for information about the club, its members, and its activities.

The intended users include current students at UNC Charlotte, prospective members interested in sports analytics, and faculty or external organizations who may want to collaborate with the club.

The website will include sections such as an About Us page, a list of club projects, information about club officers, and details about club events and campus engagement.

Dynamic Functionality on the Website

The website will incorporate interactive features using JavaScript to enhance user engagement and usability. On the Projects page, a filtering system will allow users to sort and view projects based on categories such as sport type or analysis method, making it easier to navigate and explore relevant content. This feature improves the user experience by organizing information dynamically without requiring page reloads. Additionally, the Officers page will include interactive profile cards that flip when hovered over or clicked, revealing more detailed information about each officer such as their role, major, and involvement in the club. This design keeps the page visually clean while still providing access to important details.
